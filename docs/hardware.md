# 하드웨어 메모

## 대우 IQ-2000 (CPC-300) — 재현 대상

| 항목 | 값 |
|---|---|
| 규격 | **MSX2** |
| RAM / VRAM | 128KB / 128KB |
| 한글 | **한글 2.0 조합형 고딕체** ROM 내장 |
| 키보드 | **일체형** (본체가 곧 키보드) |
| 저장장치 | FDD 없음, 테이프 인터페이스만 |
| 카트리지 | **본체 우측 상단 롬팩 슬롯** |
| 출시 | 1986~87 |
| 부팅 화면 | **MSX-TUTOR / 「아이큐 교실」** (BASIC이 아니라 내장 교육 프로그램으로 먼저 진입) |

### 대우 MSX 계열 비교 — 왜 CPC-300인가

| 모델 | 규격 | 키보드 | FDD | 한글 | 비고 |
|---|---|---|---|---|---|
| CPC-88 (IQ-1000) | MSX1 | 일체형 | 없음 | ❌ **미지원** | 한글이 안 되므로 제외 |
| **CPC-300 (IQ-2000)** | MSX2 | **일체형** | 없음 | ✅ 2.0 | ✅ **재현 대상** |
| CPC-300E | MSX2 | 일체형 | 없음 | ✅ 2.0 | 학교 납품 교육용. **조이스틱 포트 없음** |
| CPC-400 (X-II) | MSX2 | 분리형 | 1개 내장 | ✅ 3.0 | 키보드가 분리형이라 제외 |
| CPC-400S | MSX2 | 분리형 | 1개 내장 | ✅ 3.0 | 〃 |

### 재믹스(게임 전용기) 계열 — 참고

| 모델 | 번호 | 규격 | 출시 | 키보드 |
|---|---|---|---|---|
| 재믹스 | CPC-50 | MSX1 | 1985 | — |
| 재믹스 V | CPC-51 | MSX1 | — | — |
| 재믹스 수퍼 V | CPC-61 | MSX2 | 1990 | CPK-30 별매 |
| 재믹스 터보 | CPG-120 | MSX2 | 1991 | — |

📌 **초기 재믹스에는 키보드가 없어 `SELECT` 키가 필요한 조작을 할 수 없다.** 수퍼 V부터 키보드 연결이 가능해졌다.

## 재현 장비 (라즈베리파이)

| 항목 | 권장 |
|---|---|
| 보드 | **검증: Pi 3 B+.** Trixie 32-bit와 성능 튜닝 사용. Pi 4 이상은 참고 확장 구성 |
| 키보드 | 🔴 **USB 키보드 필수** — `SELECT` 키가 있어야 치트·일부 조작이 된다 |
| 화면 | 검증: 공식 7″ 터치스크린. HDMI는 대체 구성 |
| 입력 확장 | GPIO에 버튼·조이스틱을 붙여 재믹스처럼 만들 수 있다 |

## MSX 카트리지 슬롯 (과거 확장 검토)

아래 자작·덤퍼 내용은 현재 제작 범위에 포함되지 않는 참고 메모다. 완성 구성은 USB 롬팩을 사용한다.

**50핀**이고 **Z80 버스가 거의 그대로** 나온다 — 주소 A0~A15, 데이터 D0~D7, `/SLTSL`(슬롯 선택), `/RD`, `/WR`, `/MERQ`, `/IORQ`, `/RESET`, 클럭, 전원(+5V / +12V / -12V) 등.

즉 **슬롯에 꽂는 것은 Z80 버스에 직접 붙는 일**이다. 정확한 핀 배치는 작업 직전에 MSX Resource Center 문서로 재확인할 것.

### 자작 난이도 단계

| 단계 | 구성 | 난이도 |
|---|---|---|
| 32KB 단순 ROM팩 | EPROM(27C256) + 주소 디코더 | ⭐ **매퍼 불필요.** 여기서 시작 |
| 메가롬(256KB~) | 플래시 + **뱅크 스위칭 매퍼** | ⭐⭐⭐ 매퍼 방식이 여러 갈래(ASCII8/16, Konami, Konami SCC…) |
| SD 카트리지 | 플래시 + SD + 펌웨어 | ⭐⭐⭐⭐⭐ 기성품 구매가 합리적 |

📌 **매퍼 구현이 Verilog/CPLD가 쓰이는 자리다.** 74 로직으로도 되지만 CPLD(MAX II) 또는 소형 FPGA(Tang Nano) 하나로 정리된다.

## 실물 카트리지를 읽는 문제

🔴 **일반 라즈베리파이로는 실시간 구동이 불가능하다.** Z80 버스는 사이클 단위로 응답해야 하는데, 리눅스 커널 스케줄러가 언제 끼어들지 알 수 없어 타이밍을 보장할 수 없다. 그래서 FPGA 기기(재믹스 네오, SX-E 등)만 실물 슬롯을 갖는다.

**대안 세 가지**

1. ⭐ **덤퍼를 만든다** — 실시간 구동을 포기하고 팩 내용을 ROM 파일로 뽑아 openMSX로 돌린다. 타이밍이 느슨해도 되어 난이도가 크게 낮다.
   📌 **라즈베리파이 Pico(RP2040)의 `PIO`**가 이 용도에 적합하다. CPU 간섭 없이 정밀한 버스 타이밍을 만드는 전용 상태기계다. **일반 Pi보다 Pico가 맞다.**
2. **FPGA로 MSX를 만든다** — 실물 팩이 꽂히고 타이밍도 정확하나, 비싸고 한글 ROM은 별개 과제로 남는다.
3. **실기 IQ-2000을 구한다** — 가장 단순하다. 팩도 꽂히고 한글도 나온다.
