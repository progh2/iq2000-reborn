작은 전용기, 익숙한 순서

전원에서 롬팩까지.

01 / BOOT

아이큐 교실로 시작

한글이 표시되는 국산 MSX2 환경. 전원을 켜면 내장 교육 프로그램으로 들어갑니다.

02 / PLAY

USB가 곧 롬팩

게임 ROM 하나를 담은 FAT32 USB를 꽂으세요. 재시작 후 F12로 게임에 진입합니다.

03 / RETURN

팩을 빼면 처음으로

USB를 빼면 아이큐 교실로 돌아옵니다. 기기 전원은 종료 명령 후 꺼 주세요.

왜 IQ-2000인가

기억 속 컴퓨터는
한글을 알고 있었습니다.

이 프로젝트의 출발점은 한글 ROM과 「아이큐 교실」입니다. 대우 CPC-300의 환경을 openMSX로 재현하고, 라즈베리파이를 매일 켤 수 있는 작은 전용기로 만들었습니다.
